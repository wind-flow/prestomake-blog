콘텐츠 자동화는 글을 대량 생성하는 시스템보다 한 편이 아이디어에서 공개 검수까지 빠짐없이 이동하는 시스템이 먼저입니다. 상태와 담당자가 불명확하면 예약 누락과 중복 발행이 생깁니다.

## 한 개의 원장을 둡니다

콘텐츠 ID, 제목, 채널, 목표 독자, 상태, 담당자, 예정일과 공개 URL을 한 곳에서 관리합니다. 채널별 도구에 흩어진 초안을 원장과 연결하고 제목만으로 같은 콘텐츠를 식별하지 않습니다.

## 상태 전환을 정의합니다

`아이디어 → 자료 확인 → 작성 → 검수 → 예약 → 공개 확인`처럼 상태를 정합니다. 각 전환에는 필수 조건이 있어야 합니다. 출처와 이미지 권리가 확인되지 않았다면 검수 완료로 이동하지 못하게 합니다.

## 자동화할 부분

- 예정일이 다가오는 초안 알림
- 승인된 글의 예약 작업 생성
- 채널별 형식 템플릿 적용
- 공개 URL과 공개 시각 수집
- 실패 또는 누락된 게시물 알림

AI는 제목 후보, 개요와 채널별 요약을 만드는 데 활용할 수 있습니다. 사실 확인과 최종 표현은 사람이 검수하고, 존재하지 않는 경험을 만들어내지 않도록 합니다.

## 중복 발행 방지

콘텐츠 ID와 채널, 발행 슬롯을 묶은 고유 키를 사용합니다. 자동화 재실행 때 이미 공개 URL이 있으면 새 글을 만들지 않고 기존 글을 확인합니다.

## 공개 후가 마지막 단계입니다

API의 성공 응답만 믿지 말고 공개 URL이 열리는지, 제목과 본문, 링크와 이미지가 정상인지 확인합니다. 오류가 있으면 수정 이력과 원인을 남겨 다음 템플릿에 반영합니다.

콘텐츠 캘린더의 목적은 빈칸을 모두 채우는 것이 아닙니다. 자료 확인과 검수를 생략하지 않으면서 반복 작업을 줄이고, 각 콘텐츠의 현재 상태를 누구나 이해하게 만드는 것입니다.
